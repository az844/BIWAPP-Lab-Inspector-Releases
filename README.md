# BIWAPP Lab Inspector – Releases

Dieses Repository enthält ausschließlich die **signierten Installationspakete** und die
Update-Informationen (`latest.json`) des BIWAPP Lab Inspector, eines internen Werkzeugs für den
BIWAPP-Support.

- Kein Quellcode, keine Support- oder Wissensdaten, keine Zugangsdaten.
- Releases werden automatisch erstellt (als Entwurf) und erst nach Prüfung veröffentlicht.
- Installierte Programme prüfen beim Start auf neue, veröffentlichte Versionen. Jedes Update ist
  signiert; die Signatur wird vor der Installation geprüft.

Bitte keine Dateien manuell hochladen oder ändern.
